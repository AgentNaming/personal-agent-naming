# Security

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository, and include how
to reproduce what you found:
<https://github.com/AgentNaming/personal-agent-naming/security/advisories/new>

The thread stays private between you and the maintainers until an advisory is
published. Please do not open a public issue for a vulnerability. If you have no
GitHub account, open an ordinary issue saying only that you have a security
finding and asking for a private channel, and leave the details out of it.

Reports are read by a very small number of people, so expect a first reply in
days rather than hours.
